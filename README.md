# Højby Salon — Hjemmeside ✂️

Moderne, hyggelig og stilren hjemmeside til **Højby Salon** (Højby Frisør Salon) i Højby, Odense.

## 📌 Om Projektet
Hjemmesiden er udviklet i React + Vite + Lucide Icons med et varmt, venligt og stilrent design.
Der er ingen online booking-systemer — kunder opfordres direkte til at ringe på **20 18 89 03** for tidsbestilling eller komme forbi som drop-in.

### 📍 Salon Information
- **Adresse**: Svendborgvej 321, 5260 Odense (Højby)
- **Telefon**: [20 18 89 03](tel:+4520188903)
- **Åbningstider**:
  - Tirsdag – Fredag: 10:00 – 17:30
  - Lørdag – Søndag: 10:00 – 15:00
  - Mandag: Lukket

### 💈 Priser
- **Herreklip**: 200,- kr.
- **Børneklip** (under 12 år): 150,- kr.
- **Pensionistklip**: 150,- kr.
- **Skægtrimning**: 120,- kr.
- **Kombi (Herreklip + Skæg)**: 280,- kr.

---

## 🚀 Kør Projektet Lokalt

1. **Installer afhængigheder**:
```bash
npm install
```

2. **Start udviklingsserver**:
```bash
npm run dev
```

3. **Byg til produktion**:
```bash
npm run build
```

---

## 📄 Sidestruktur (6 Sider)
- **Forside**: Hero med salonbillede, Call-CTA (`20 18 89 03`), intro og højdepunkter.
- **Om Os**: Salonens historie, værdier og stemning.
- **Ydelser & Priser**: Komplet prisoversigt med beskrivelser og praktisk info (parkering, betaling m.m.).
- **Galleri**: Billeder af salonens facade og interiør med lightbox-visning.
- **Anmeldelser**: Kundeudtalelser og tilbagemeldinger.
- **Kontakt**: Telefonopkaldskort, åbningstider, adresse og Google Maps-kort.
